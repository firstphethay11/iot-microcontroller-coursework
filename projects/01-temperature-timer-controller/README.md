# Project 1: เครื่องควบคุมอุปกรณ์ไฟฟ้าตามอุณหภูมิแบบตั้งเวลา
### Temperature & Timer-Based Electrical Device Controller (ESP32 / MicroPython)

## 1. คุณสมบัติของระบบ (Key Features)
- **การควบคุมตามอุณหภูมิ:** อ่านค่าอุณหภูมิและความชื้นแบบเรียลไทม์จากเซนเซอร์ DHT22 เพื่อควบคุมการเปิด-ปิดโหลดไฟฟ้า
- **การควบคุมตามเวลา (RTC):** กำหนดช่วงเวลาเปิด-ปิดอัตโนมัติได้อย่างน้อย 2 ช่วงเวลา (T1 และ T2) ด้วยความแม่นยำสูงจาก DS3231 RTC
- **การป้อนคำสั่งผ่านแป้นพิมพ์:** รองรับ 14 คำสั่งควบคุมผ่าน Keypad Matrix 4x4 โดยใช้รูปแบบ *<CMD>#
- **การแสดงผลผ่าน LCD 16x2:** แสดงเวลาปัจจุบัน สถานะเปิด/ปิดอุปกรณ์ อุณหภูมิ และเมนูการตั้งค่า
- **การจดจำข้อมูล (Non-Volatile Storage):** บันทึกค่าพารามิเตอร์ทั้งหมดลงไฟล์ data.txt ในหน่วยความจำแฟลชของ ESP32 ข้อมูลไม่สูญหายเมื่อไฟดับ

## 2. แผนภาพการเชื่อมต่อ (Pin Interfacing)
- DHT22 Data: GPIO 4
- DS3231 RTC / LCD 16x2 I2C: SCL: GPIO 22, SDA: GPIO 21
- Relay Active-HIGH: GPIO 25
- 4x4 Keypad Rows: GPIO 12, 13, 14, 15
- 4x4 Keypad Cols: GPIO 26, 27, 32, 33

## 3. รายการคำสั่งลัด (Command Reference)
- *1#: ตั้งเวลาปัจจุบัน (Set System Time)
- *2#: บังคับปิดโหลดทันที (DEV OFF)
- *3#: บังคับเปิดโหลดทันที (DEV ON)
- *4#: ปิดโหมดตั้งเวลา (TIMER OFF)
- *5#: เปิดโหมดตั้งเวลา (TIMER ON)
- *6#: กำหนดเวลาเริ่มช่วงที่ 1 (Set Start Time 1)
- *7#: กำหนดเวลาหยุดช่วงที่ 1 (Set Stop Time 1)
- *8#: แสดงเวลาช่วงที่ 1 (Show Range 1)
- *9#: กำหนดเวลาเริ่มช่วงที่ 2 (Set Start Time 2)
- *10#: กำหนดเวลาหยุดช่วงที่ 2 (Set Stop Time 2)
- *11#: แสดงเวลาช่วงที่ 2 (Show Range 2)
- *12#: กำหนดอุณหภูมิเริ่ม (Set Start Temp)
- *13#: กำหนดอุณหภูมิหยุด (Set Stop Temp)
- *14#: แสดงขอบเขตอุณหภูมิ (Show Temp Range)
